# SBTI

SBTI is a playful personality quiz app for iPhone. Answer 31 quick questions, discover one of 27 silly personality types, browse the ranking, and save a shareable result card.

## Website localization

This repository contains the static website and App Store copy, not the app source code. Each website language has privacy, support, and marketing HTML pages. The language navigation keeps visitors on the same kind of page and works without JavaScript.

- New page suffixes: `RO`, `UK`, `RU`, `ID`, `TR`, `PT`, `ES`, `AR`.
- Portuguese uses `pt-PT`; Spanish uses `es-ES`; Arabic HTML uses `ar` and App Store metadata uses `ar-SA`.
- Arabic pages use `dir="rtl"`, with left-to-right URLs isolated for readability.
- Shared navigation and localization styles: `assets/localization.css`.
- Keep the HTML, corresponding Markdown copy, language links, and `APP_STORE_METADATA.md` in sync when updating a translation.
- These website translations do not add languages to the app binary or create translated screenshots.

Preview locally with `python3 -m http.server 8000`, then open `http://localhost:8000`.
