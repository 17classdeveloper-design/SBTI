Assistance SBTI

Si vous avez besoin d’aide avec SBTI, ouvrez un ticket sur GitHub Issues :

https://github.com/17classdeveloper-design/SBTI/issues

Sujets fréquents

  • Enregistrer une carte de résultat dans la photothèque
  • Changer la langue de l’app
  • Le classement ne s’actualise pas
  • Questions sur la validation App Store ou la confidentialité
  • Signaler une faute ou un problème de traduction

Merci d’indiquer le modèle de votre appareil, la version d’iOS, la version de l’app et une brève description du problème.
